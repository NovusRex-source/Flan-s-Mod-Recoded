# Content-pack definitions

Generated by `tools/generate_docs.py` from the Kotlin data classes - do not edit by hand.

Every file lives at `data/<namespace>/flansmod/<folder>/<name>.json`; its id is `<namespace>:<name>`. Fields
are optional unless marked **required**. Distances are in blocks, times in ticks (20 per second), angles in
degrees. Unknown fields are ignored, comments and trailing commas are allowed.

## Guns

`data/<ns>/flansmod/guns/<name>.json` - A gun as described by a content pack in `data/<namespace>/flansmod/guns/<name>.json`. All fields except `name` have defaults, so a minimal gun is just `{ "name": "Pistol" }`. Distances are in blocks, times in ticks, angles in degrees.

| Field | Type | Default | Description |
|---|---|---|---|
| `name` | text | **required** | Display name (a lang key `<type>.<namespace>.<name>` overrides it). |
| `model` | ModelInfo | `{}` | GeckoLib model, texture and animations (defaults follow the gun id). |
| `damage` | number | `5` | Damage per bullet (per pellet for shotguns). |
| `headshot_multiplier` | number | `1.5` | Damage multiplier for hits at head height. |
| `rpm` | integer | `300` | Rounds per minute. Capped at 1200 (one shot per tick). |
| `fire_mode` | FireMode | `"semi"` | Default fire mode of a new gun. |
| `fire_modes` | list of FireMode | `[]` | Modes the selector cycles through; defaults to safe + `fireMode`. |
| `burst_count` | integer | `3` | Rounds per trigger pull in `burst` mode. |
| `magazines` | list of id | `[]` | Magazine ids this gun accepts (magazines may also list guns themselves). |
| `reload_ticks` | integer | `40` | Time to swap a magazine (or load one round into an internal magazine). |
| `pellets` | integer | `1` | Bullets per shot (shotguns); ammo may override it. Each pellet deals `damage`. |
| `velocity` | number | `15.0` | Muzzle velocity in blocks per tick. |
| `gravity` | number | `0.02` | Downward acceleration per tick (bullet drop). |
| `drag` | number | `0.99` | Velocity multiplier per tick. |
| `lifetime_ticks` | integer | `40` | How long a bullet flies before it disappears (with `velocity`: the range). |
| `spread` | number | `2` | Cone half-angle when hip firing / aiming. |
| `ads_spread` | number | `0.3` | Spread while aiming down sights. |
| `ads_zoom` | number | `1.3` | FOV divisor while aiming down sights. |
| `ads_move_speed` | number | `0.6` | Movement speed multiplier while aiming down sights. |
| `recoil` | Recoil | `{}` | Camera kick per shot. |
| `scope` | Scope | - | Built-in optic (e.g. a fixed sniper scope). A sight attachment replaces it. |
| `sounds` | Sounds | `{}` | Sound event ids. |
| `display` | map text → Transform | `{}` | Item display transforms in Blockbench/vanilla format, keyed by display context (`firstperson_righthand`, `thirdperson_righthand`, `gui`, `ground`, `fixed`, `head`, ...) plus `ads` for the first-person pose while fully aimed. Missing keys fall back to `Transform.DEFAULTS`. |
| `tracer` | Tracer | `{}` | Visual bullet trail; `null` disables tracers for this gun. |
| `attachment_slots` | list of text | `[]` | Attachment slots this gun offers, e.g. `["sight", "barrel"]`. |
| `rail_ads` | number | - | `ads` translation Y (1/16 block) that puts a line of sight lying exactly on the sight rail at the screen centre. Sight attachments then aim through their own optic (`AttachmentDefinition.adsHeight` above the rail). |
| `category` | text | - | Weapon class for sorting and tooltips: `pistol`, `smg`, `rifle`, `dmr`, `sniper`, `shotgun`, `lmg`, `launcher`, ... |
| `mounted` | true/false | `false` | Vehicle weapon: only fired from a vehicle seat, never listed as an item. |
| `drop` | true/false | `false` | Bombs: the round (a projectile) is released with the vehicle's own velocity instead of being fired with `velocity`, and falls under the projectile's gravity. |
| `faction` | id | - | Side this belongs to (a `FactionDefinition` id): faction creative tab and tooltip line. |

### ModelInfo

GeckoLib asset ids. `geo`/`animations` are relative to `geckolib/models|animations/`, `texture` is a full path.

| Field | Type | Default | Description |
|---|---|---|---|
| `geo` | id | - | GeckoLib model id (`geckolib/models/...`); default derived from the definition id. |
| `texture` | id | - | Texture path; default derived from the definition id. |
| `animations` | id | - | GeckoLib animation file id; default derived from the definition id. |

**FireMode** (text): `safe`, `semi`, `auto`, `burst`

### Recoil

| Field | Type | Default | Description |
|---|---|---|---|
| `pitch` | number | `1.5` | Upward kick per shot in degrees. |
| `yaw` | number | `0.5` | Random horizontal kick in ±yaw. |
| `recovery` | number | `0.2` | Fraction of the accumulated kick recovered per tick once firing stops. |
| `ads_multiplier` | number | `0.6` | Recoil multiplier while aiming. |

### Scope

What you see while fully aimed through an optic. `overlay` is a full-screen texture (like the spyglass) that also hides the gun model; without it you look along the gun's own sights.

| Field | Type | Default | Description |
|---|---|---|---|
| `overlay` | id | - | Full-screen texture shown while fully aimed (hides the gun model). |
| `night_vision` | true/false | `false` | Grants night vision while aiming (applied by the server). |
| `thermal` | true/false | `false` | Living entities within `thermalRange` get the glowing outline while aiming (client only). |
| `thermal_range` | number | `64.0` | Range of the thermal highlight. |

### Sounds

| Field | Type | Default | Description |
|---|---|---|---|
| `shoot` | id | - | Played on every shot. |
| `reload` | id | - | Played when reloading. |
| `empty` | id | - | Dry click (empty or safe). |

| `translation` | list of number | `[0, 0, 0]` | Offset in 1/16 block. |
| `scale` | list of number | `[1, 1, 1]` | Scale factors. |

Client-side bullet trail. `color` is `#RRGGBB`, sizes in blocks.

| Field | Type | Default | Description |
|---|---|---|---|

## Magazines

`data/<ns>/flansmod/magazines/<name>.json` - A magazine type from `data/<namespace>/flansmod/magazines/<name>.json`. Holds up to `capacity` rounds of one ammo type of its `caliber`. A gun accepts it if either lists the other.

| Field | Type | Default | Description |
|---|---|---|---|
| `name` | text | **required** | Display name (a lang key `<type>.<namespace>.<name>` overrides it). |
| `caliber` | text | **required** | Caliber id; rounds of this caliber fit (`caliber.flansmod.<caliber>` names it). |
| `capacity` | integer | **required** | Rounds it holds. |
| `guns` | list of id | `[]` | Guns that accept it (guns may also list magazines). |
| `reload_multiplier` | number | `1` | Multiplies the gun's reload time when this magazine is inserted (drums are slower). |
| `icon` | id | - | Item model id of the item icon. |
| `internal` | true/false | `false` | Built into the gun (shotgun tube, launcher, tank breech): never an item. Reloading loads loose rounds straight from the inventory, unloading returns them as rounds. |

## Ammunition

`data/<ns>/flansmod/ammo/<name>.json` - A cartridge type from `data/<namespace>/flansmod/ammo/<name>.json`. It is loaded into magazines of the same `caliber`; its modifiers apply to every shot fired with it.

| Field | Type | Default | Description |
|---|---|---|---|
| `name` | text | **required** | Display name (a lang key `<type>.<namespace>.<name>` overrides it). |
| `caliber` | text | **required** | Caliber id; fits magazines of the same caliber. |
| `max_stack` | integer | `64` | Stack size of the item. |
| `icon` | id | - | Item model (an `assets/<ns>/items/<name>.json` id) used for the ammo item. |
| `damage_multiplier` | number | `1` | Multiplies the gun's damage. |
| `velocity_multiplier` | number | `1.0` | Multiplies the gun's muzzle velocity. |
| `spread_multiplier` | number | `1` | Multiplies the gun's spread. |
| `pellets` | integer | - | Overrides the gun's pellet count (buckshot vs. slug). |
| `fire_seconds` | number | `0` | Sets targets on fire for this many seconds (incendiary rounds). |
| `armor_piercing` | true/false | `false` | Ignores armour (uses the `flansmod:gun_ap` damage type). |
| `tracer` | Tracer | - | Overrides the gun's tracer look. |
| `projectile` | id | - | Fires this grenade definition as a projectile instead of a bullet (rockets, 40mm grenades). |
| `flak` | Flak | - | Anti-aircraft shells (HE-FRAG): burst near aircraft, or in the air when the fuse runs out. |
| `explosion` | number | `0` | Explosive and HEI rounds: a small explosion of this power where the round hits (0 = none). It hurts what is around but never breaks blocks; with `fire_seconds` it also sets the spot alight. |

### Flak

Proximity and time fuze of an anti-aircraft round: it bursts when it passes within `proximity` blocks of an aircraft (or a flying mob or a player gliding with an elytra), else after `fuseTicks` (the gun's bullet lifetime when unset). The burst is an explosion of `power` that breaks no blocks.

| Field | Type | Default | Description |
|---|---|---|---|
| `proximity` | number | `3.0` |  |
| `power` | number | `1.5` |  |
| `fuse_ticks` | integer | - |  |

## Attachments

Visuals: the gun's GeckoLib model may contain a bone `attachment_<name>` (shown only while this attachment is installed) and `default_<slot>` (hidden while anything occupies that slot, e.g. iron sights).

| Field | Type | Default | Description |
|---|---|---|---|

| `slot` | text | **required** | Attachment slot it goes into. |
| `guns` | list of id | `[]` | Only these guns (default: every gun with the slot). |
| `damage_multiplier` | number | `1` | Multiplies damage. |
| `spread_multiplier` | number | `1` | Multiplies spread. |
| `recoil_multiplier` | number | `1` | Multiplies recoil. |
| `velocity_multiplier` | number | `1.0` | Multiplies muzzle velocity. |
| `reload_multiplier` | number | `1` | Multiplies reload time. |
| `ads_move_speed_multiplier` | number | `1` | Multiplies movement speed while aiming. |
| `ads_zoom` | number | - | Replaces the gun's `ads_zoom` (scopes). |
| `shoot_sound` | id | - | Replaces the gun's shoot sound (suppressors). |
| `hide_tracer` | true/false | `false` | Suppressors: no tracers. |
| `scope` | Scope | - | Optic effects while aiming through this sight (overlay, night vision, thermal). |
| `ads_height` | number | `0` | Height of this sight's line of sight (dot or lens centre) above the gun's rail, in model pixels. Guns with `rail_ads` aim exactly through it; for other guns the aiming pose is just lowered by this amount. |
| `icon` | id | - | Item model (an `assets/<ns>/items/<name>.json` id) used for the attachment item. |
| `deploy` | Deploy | - | Bipods and tripods: much steadier while the gun is set down (prone, or crouching unless `Deploy.proneOnly`). |

## Grenades, mines and launcher projectiles

`data/<ns>/flansmod/grenades/<name>.json` - A throwable from `data/<namespace>/flansmod/grenades/<name>.json`. Effects are optional and combine: a grenade may explode, leave a smoke cloud and/or blind players who can see it.

| Field | Type | Default | Description |
|---|---|---|---|
| `name` | text | **required** | Display name (a lang key `<type>.<namespace>.<name>` overrides it). |
| `fuse_ticks` | integer | `60` | Ticks until detonation; ignored when `contact` detonates first. |
| `contact` | true/false | `false` | Detonate on the first impact instead of bouncing. |
| `throw_velocity` | number | `1.2` | Throw speed in blocks per tick. |
| `gravity` | number | `0.05` | Downward acceleration per tick. |
| `bounciness` | number | `0.4` | Fraction of speed kept when bouncing off blocks. |
| `cooldown_ticks` | integer | `20` | Time between throws. |
| `max_stack` | integer | `16` | Stack size of the item. |
| `throwable` | true/false | `true` | False for launcher projectiles (rockets, 40mm): no hand throwing, not listed as an item. |
| `trail` | true/false | `false` | Smoke trail while flying (rockets). |
| `explosion` | Explosion | - | Explosion on detonation. |
| `smoke` | Smoke | - | Smoke cloud on detonation. |
| `flash` | Flash | - | Blinding flash on detonation. |
| `detonate_sound` | id | - | Sound event played on detonation. |
| `icon` | id | - | Item model (an `assets/<ns>/items/<name>.json` id) used for the item and the thrown entity. |
| `mine` | Mine | - | A mine: placed on the ground with right click instead of thrown, goes off when its `Mine.trigger` passes over it. |
| `faction` | id | - | Side this belongs to (a `FactionDefinition` id): faction creative tab and tooltip line. |

### Explosion

`breakBlocks`: a full vanilla (TNT-like) explosion. Otherwise the vanilla explosion only hurts and pushes, and `blockDamage` does the limited, grenade-type-specific damage to the surroundings.

| Field | Type | Default | Description |
|---|---|---|---|
| `power` | number | `2.5` | Explosion strength (TNT is 4). |
| `fire` | true/false | `false` | Sets the area on fire. |
| `break_blocks` | true/false | `false` | Full TNT-like block destruction (rockets, shells). |
| `block_damage` | BlockDamage | - | Limited damage to weak blocks around it. |

### Smoke

| Field | Type | Default | Description |
|---|---|---|---|
| `radius` | number | `4.0` | Radius in blocks. |
| `duration_ticks` | integer | `300` | How long it lasts. |

### Flash

Blinds living entities within `radius` that have line of sight to the grenade.

| Field | Type | Default | Description |
|---|---|---|---|
| `radius` | number | `12.0` | Radius in blocks. |
| `duration_ticks` | integer | `100` | How long it lasts. |

### Mine

`trigger` `personnel`: any living entity or vehicle steps on it; `vehicle`: only vehicles (anti-tank mines). `vehicleDamage` goes straight into the vehicle part above the mine (tracks, wheels) on top of the explosion.

| Field | Type | Default | Description |
|---|---|---|---|
| `trigger` | Trigger | `"personnel"` | `personnel` (anyone) or `vehicle` (vehicles only). |
| `arm_ticks` | integer | `40` | Time after laying before it is live. |
| `radius` | number | `0.7` | Trigger radius. |
| `vehicle_damage` | number | `0` | Extra damage to the vehicle part above it. |

### BlockDamage

Light damage to the surroundings: within `radius` blocks, blocks whose blast resistance is at most `maxResistance` break with `chance` (falling off to 0 at the edge). Typical: fragmentation 0.5 (glass, leaves, plants, some soil), concussion/HE 1.5 (also sand, gravel, wood planks are 3), demolition 6 (stone). Off when the `tnt_explodes` gamerule is false.

| Field | Type | Default | Description |
|---|---|---|---|
| `radius` | number | `2.0` | Radius in blocks. |
| `max_resistance` | number | `0.5` | Strongest blast resistance it breaks. |
| `chance` | number | `0.7` | Chance per block (falls off to the edge). |
| `drops` | number | `0.3` | Chance a broken block drops itself. |

**Trigger** (text): `personnel`, `vehicle`

## Vehicles

`data/<ns>/flansmod/vehicles/<name>.json` - A driveable from `data/<namespace>/flansmod/vehicles/<name>.json`. Positions are in blocks in vehicle space: `[right, up, forward]` relative to the centre of the vehicle's footprint at ground level. Speeds are in blocks per tick, angles in degrees. The GeckoLib model is built facing north (-Z), like guns.

| Field | Type | Default | Description |
|---|---|---|---|
| `name` | text | **required** | Display name (a lang key `<type>.<namespace>.<name>` overrides it). |
| `type` | VehicleType | `"car"` | `car`, `tank`, `static` (emplacements such as mortars), `plane` or `helicopter`. |
| `model` | ModelInfo | `{}` | GeckoLib model, texture and animations (defaults follow the vehicle id). |
| `width` | number | `2.5` | Footprint (square) and height; only used when there are no `parts` (otherwise the parts are the hitbox). |
| `height` | number | `1.6` | Hit box height (without `parts`). |
| `health` | number | `100` | Hull health: the vehicle is destroyed when it reaches 0. |
| `armor` | number | `0` | Fraction of bullet/melee damage absorbed by the hull; armour-piercing rounds and explosions ignore it. |
| `parts` | map text → VehiclePart | `{}` | Hit boxes by name. Bullets only hit the vehicle where they pass through a part; each part has its own health and a `PartRole` that decides what breaks with it. Without parts the whole footprint is one hull part. |
| `upgrade_slots` | list of text | `[]` | Upgrade slots (see `VehicleUpgradeDefinition`), e.g. `["engine", "armor"]`. |
| `repair` | Repair | `{}` | Right click with this item to repair the hull and every part by `Repair.amount` health. |
| `step_height` | number | `1` | Highest step it drives up. |
| `max_speed` | number | `0.8` | Top speed in blocks per tick. |
| `max_reverse_speed` | number | `0.25` | Top speed backwards. |
| `acceleration` | number | `0.02` | Speed gained per tick at full throttle. |
| `braking` | number | `0.06` | Speed lost per tick while braking (jump key). |
| `drag` | number | `0.02` | Fraction of speed lost per tick when coasting. |
| `turn_speed` | number | `4` | Degrees per tick at full lock. Cars need speed to turn, tanks turn on the spot. |
| `water_speed` | number | `0.2` | Speed multiplier in water; 0 stalls the engine (amphibious vehicles use 1). |
| `fuel` | Fuel | `{}` | Tank and fuel type. |
| `storage` | integer | `0` | Cargo slots (a multiple of 9, up to 54): opened as a chest from the vehicle menu, or with sneak + right click holding an item. The contents stay in the item when the vehicle is picked up and drop when it is destroyed. |
| `flight` | FlightDefinition | `{}` | Planes and helicopters: how they fly (see `FlightDefinition`). |
| `seats` | list of Seat | one default seat | Seat 0 is the driver's (the pilot's). |
